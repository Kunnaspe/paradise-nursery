# Paradise Nursery

Paradise Nursery is an e-commerce website specializing in a wide variety of houseplants. We are passionate about bringing nature into homes and helping plant lovers find their perfect green companions.

## Project Details

- **Project Name**: Paradise Nursery
- **Description**: A React-based e-commerce platform for houseplants
- **Technology Stack**: React + Vite + Redux
- **Purpose**: Provide customers with an easy-to-use interface to browse, select, and purchase houseplants

## Features

- Browse a wide variety of houseplants
- View detailed plant information
- Shopping cart functionality
- User-friendly interface
- Responsive design

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## About Paradise Nursery

Paradise Nursery is dedicated to making houseplants accessible to everyone. Our mission is to help people create their own indoor paradise with beautiful, healthy plants.
